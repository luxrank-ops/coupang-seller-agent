# 쿠팡 셀러 AI 비서 (Coupang Seller Copilot)

Cloudflare Workers Edge 기반 10년 차 셀러 위탁판매 자동화 및 엄격한 5단계 소싱 추천 웹 애플리케이션입니다.

## 🚀 배포 정보
- **서비스 주소**: https://coupang-seller-agent.luxrank.workers.dev/
- **런타임**: Cloudflare Workers
- **호스팅**: Cloudflare Global Edge Network

## 🛡️ 핵심 기능
1. **엄격한 5단계 추천 상품 검색**: 역마진 0%, 3무 원칙, 지재권 100% 클린, 무설치 플러그앤플레이, B2B/마니아 정예 소싱
2. **실시간 마진/권장판매가 자동 계산**: 도매원가 + 배송비 + 수수료율(10.8%) 기반 목표마진율 30% 즉시 산출
3. **10년 차 셀러 AI SEO 생성**: 상품명 최적화, 검색 태그 12종 자동 추출, 핵심 소구점 3선
4. **쿠팡 WING OpenAPI 원클릭 상품 등록**: OpenAPI Key 연동 및 즉시 등록 접수

## 🛠️ 개발 및 배포
```bash
npm install
npm run deploy
```
