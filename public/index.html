    더 넓은 소싱의 시작

    각 도매몰의 검색은 외부 사이트에서 열립니다. 회원가입·로그인이 필요할 수 있으며, 검색 정책에 따라 결과가 달라질 수 있습니다. 이 앱이 모든 도매몰의 상품을 실시간 수집하는 것은 아닙니다.

    한두 개 상품만 추가하려면 를 이용하세요.

    실제 상품을 이곳에서 검색하려면

    방법 1. CSV 가져오기 — 이용 권한이 있는 공급사의 상품 파일을 업로드하세요. 도매몰별 파일은 제공된 양식의 열 이름에 맞춰주세요.

    방법 2. 도매꾹 OpenAPI — 서버에서 발급받은 API 키를 연결하면 실시간 목록 검색을 사용할 수 있습니다.

    npx wrangler secret put DOMEGGOOK_API_KEY운영자용 설정입니다. 키를 채팅이나 브라우저에 입력하지 마세요. 그 외 도매몰은 현재 외부 검색·CSV 방식입니다.
